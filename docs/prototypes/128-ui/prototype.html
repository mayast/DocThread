What DocThread does

DocThread brings Word-style inline review to Markdown files and Azure DevOps work items. Reviewers highlight rendered text and start threaded discussions right where the content lives — no pull-request detours and no exporting to Word and back.

Bring your own document

Start here when you want to review real content. Paste a GitHub file link, an Azure Repos file link, or an Azure DevOps work item link into the bar at the top.

Leave your first comment

Select any text in this document with your mouse. A composer appears — type your feedback and choose an intent. Your note is anchored to that exact phrase.
